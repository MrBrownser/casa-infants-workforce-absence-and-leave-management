# Design System: Casa d'Infants

## Product Context

- **What this is:** A time and leave (absence) management web app for Casa d'Infants, a 24/7 residential service for children and teenagers run by FASI (Fundació Acció Social Infància).
- **Who it's for:** First release: the coordinator / director, who reviews and approves requests and watches team coverage. Mostly desktop, plus quick checks and approvals on mobile. Later: the educators themselves (rotating shifts, mobile-first).
- **Space/industry:** Social sector, workforce absence and leave management.
- **Project type:** Web app (internal tool). UI copy in Catalan; code in English.
- **Memorable thing:** *Warm, like home.* Every decision below serves this.

## Aesthetic Direction

- **Direction:** Organic and warm, "clay". Inspired by FASI's plasticine house: handmade, soft, solid.
- **Decoration level:** Intentional. Warm cream surfaces, soft "modelled" shadows, a clay-house illustration on sign-in and empty states. No gradients, no decorative blobs, no stock photos.
- **Mood:** Opening the app should feel like walking into the Casa: calm, welcoming, made by people who care. Never a corporate HR dashboard.
- **Brand link:** Base look from the clay house; FASI connection through terracotta/rust tones and serif headings (FASI uses Bree Serif).
- **Reference:** https://www.fasi.cat/serveis/casa-dinfants/ (clay house image, rust palette).
- **Preview:** generated by /design-consultation at `~/.gstack/projects/MrBrownser-casa-infants-workforce-absence-and-leave-management/designs/design-system-20261004/design-preview.html`.

## Typography

Both families are free (Google Fonts, SIL OFL) and are self-hosted through `next/font/google`, so no request reaches Google from the user's browser (GDPR-friendly).

- **Display / headings:** **Fraunces**, weight 600, `font-variation-settings: "SOFT" 100, "WONK" 0`, optical sizing on. The SOFT axis rounds the serifs, as if modelled in clay. Use only at **20px and above** (page titles, section titles, greeting, empty states). Tailwind: `font-display`.
- **Body / UI / labels:** **Figtree**, 400 for text, 500 for UI labels and nav, 600 for buttons and emphasis. Tailwind: `font-sans` (default).
- **Data / numbers:** Figtree with `font-variant-numeric: tabular-nums` (Tailwind `tabular-nums`) for dates, day counts, balances and any column of numbers. No monospace font.
- **Never:** Inter, Roboto, Arial, Helvetica, Open Sans, Lato, Montserrat, Poppins, Space Grotesk as primary type.

### The honey rule (`--color-accent`, Mel `#E9B44C`)

Honey has **one meaning only: something is waiting for the coordinator's decision.**

- 4px honey left border on a pending request card.
- Honey badge on the "Sol·licituds" nav item with the pending count.
- Dashed honey outline for a pending leave bar in the team calendar.
- Coverage conflicts that need a decision ("3 absències la setmana del 10 d'agost").

Never use honey for decoration, emphasis, success, active/selected states or large fills. If you reach for honey with a second meaning, use the semantic layer instead.

### Semantic layer

| Token                       | Hex (text / bg)         | Usage |
|-----------------------------|-------------------------|-------|
| `--color-success` / `-bg`   | `#5E7F5A` / `#E5EEE2`   | Approved, saved |
| `--color-warning` / `-bg`   | `#C98A1B` / `#FBEFD3`   | Warnings that do not need a decision |
| `--color-error` / `-bg`     | `#B42328` / `#F8E1E1`   | Validation errors, failures, destructive actions |

Error crimson sits close to terracotta, so **errors always carry an icon and text**, never color alone, and destructive buttons use the outlined style (crimson text + light border), not a filled terracotta button.

### Leave types (team calendar, tags)

| Type              | Bar / tag bg | Text      | Dot       |
|-------------------|--------------|-----------|-----------|
| Vacances          | `#F2D3C6`    | `#8A3015` | `#A63D1F` |
| Baixa             | `#DDEBEF`    | `#2F5F6E` | `#5E95A6` |
| Assumptes propis  | `#E6E2D0`    | `#55583F` | `#8C8A63` |
| Formació          | `#E9DDE8`    | `#6B4A67` | `#8E6A8A` |

Status is shown by **texture, not badges**: approved = solid bar; pending = dashed honey outline with a dot; cancelled/past = reduced opacity. Sick leave is shown only as "Baixa", **never with a diagnosis or reason** (health data, GDPR Art. 9).

### Dark mode

Redesigned surfaces, warm not grey: background `#1E1814`, card `#28201B`, muted surface `#34312A`, border `#3A2F28`, text `#F3EBE1`, muted text `#B5A79B`, primary lifted to `#E07B57` (with dark text on it), honey unchanged. Applied with `html[data-theme="dark"]`; nothing toggles it yet.

## Spacing

- **Base unit:** 4px.
- **Density:** Comfortable on desktop (cards 16–24px padding, 24px between sections). On mobile, touch targets of at least 44px; approve/reject buttons are full-width halves.
- **Scale:** 2xs(2) xs(4) sm(8) md(16) lg(24) xl(32) 2xl(48) 3xl(64).

## Layout

- **Approach:** Grid-disciplined.
- **Desktop:** slim top bar (house mark + "Casa d'Infants" wordmark in Fraunces, nav, avatar). **No sidebar**: the coordinator needs 3–4 sections (Inici, Calendari, Sol·licituds, Equip). Home = greeting + stat row + two zones (pending list ~360px | team calendar).
- **Mobile (< 768px):** top title area + bottom tab bar with the same 4 sections; pending count badge in honey.
- **Max content width:** 1280px.
- **Border radius (soft, hierarchical):**

| Context                                | Tailwind      | Value |
|----------------------------------------|---------------|-------|
| Cards, panels, modals, calendar frame  | `rounded-2xl` | 20px  |
| Request cards, stat cards              | `rounded-xl`  | 16px  |
| Buttons, inputs, nav pills             | `rounded-lg`  | 12px  |
| Small buttons, calendar bars, tags     | `rounded-md`  | 8px   |
| Tiny controls                          | `rounded-sm`  | 6px   |
| Avatars, dots, badges                  | `rounded-full`| 9999px |

Do not apply 20px radii to dense elements (table cells, calendar bars): it reads toy-like.

### Clay depth

- **Card shadow** (`shadow-clay`): `inset 0 1px 0 rgba(255,255,255,.7), 0 1px 2px rgba(46,33,27,.06), 0 8px 20px -10px rgba(46,33,27,.18)`. Soft and warm, never a hard drop shadow.
- **Primary button:** a 2px darker bottom edge (`0 2px 0 #7A2A12`) that disappears on press while the button moves down 2px: the button "presses into the clay".

## Motion

- **Approach:** Minimal-functional, with one signature detail (button press).
- **Easing:** enter `ease-out`, exit `ease-in`, move `ease-in-out`.
- **Duration:** micro 50–120ms (press, hover), short 150–200ms (default), medium 250–350ms (panels, dialogs).
- No entrance animations on list items, no scroll-driven animation, nothing that delays the user.

## Anti-Patterns

- Purple/violet gradients, gradient buttons, 3-column icon feature grids, centered-everything layouts.
- Uniform bubbly radius on every element.
- Honey for anything other than "needs a decision".
- Badge parades for status (use texture).
- Hard, dark box shadows.
- Fraunces below 20px or for UI labels.
- Corporate or passive UI copy. Write in warm, direct Catalan ("Bon dia, Marta", "No queda res pendent").
